## Overview

iZotope Stutter Edit 2 creates real-time glitch, stutter, buffer, and loop effects triggered by MIDI notes, enabling expressive electronic music performance and EDM production.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **iZotope Stutter Edit** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **MIDI Triggers** | MIDI notes trigger different stutter and glitch effects |
| **Gesture Library** | Library of gesture presets covering stutter, blur, and granular |
| **Buffer Manipulation** | Buffer looping, reversing, and stuttering synced to tempo |
| **Automation** | Automate gesture parameters for evolving stutter compositions |
